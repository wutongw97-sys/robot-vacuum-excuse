A one-line excuse from a robot vacuum for missing a spot, written by a small program for make.fun's "The Robot Vacuum's Best Excuse" bounty: "My lidar mistook that dust bunny for a sleeping pet, so I tiptoed around it. I have manners."

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt`.
